# Fellowship Bot

A Telegram bot for managing fellowship members and schedules.

## Features
- Member management
- Attendance tracking
- Schedule reminders

## Setup
1. Clone the repository
2. Run `npm install`
3. Create `.env` file with `BOT_TOKEN=your_token`
4. Run `node index.js`

## Technologies
- Node.js
- Telegraf (Telegram Bot Framework)
- SQLite database
